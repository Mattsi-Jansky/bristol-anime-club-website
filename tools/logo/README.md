# Logo

`public/logo.svg` is generated by `build_logo.py`. Edit the shapes and colours in
the script, not the SVG, then rebuild:

```sh
pip install fonttools          # once
python3 tools/logo/build_logo.py
npm run images                 # re-render the PNGs and share image that use the logo
```

The script converts the lettering to outlines, so it needs two fonts in
`tools/logo/fonts/`. They're too large to keep in the repository, so download them
once:

```sh
mkdir -p tools/logo/fonts
# Google Fonts serves static TTFs; ask its CSS API for the file URL, then download it.
font() { curl -sL -o "tools/logo/fonts/$2" "$(curl -s "https://fonts.googleapis.com/css2?family=$1" | grep -o 'https://[^)]*' | head -1)"; }
font "Luckiest+Guy" LuckiestGuy.ttf
font "Noto+Sans+JP:wght@500" NotoSansJP.ttf
```

- **Luckiest Guy** (Apache 2.0): "NIME CLUB" and "BRISTOL & BEYOND"
- **Noto Sans JP**, weight 500 (SIL Open Font License): 日本のアニメ

The favicon, `public/favicon.svg`, is a separate hand-written SVG: a simplified
version of the tower for small sizes. Edit it directly.
